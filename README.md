The application allows users to share files directly with each other, without going through an intermediary server. However, to manage users and file indexing, a central server may be implemented. The central server stores user accounts, the file catalog, and the addresses of machines with those files.

The required features include:
-User account creation.
-User login.
-Users can search for files of interest by file name. The server returns the addresses of machines that have these files for the user to choose.
-Users can download files from a specific machine.
-The application reports indexing errors in case of unsuccessful downloads. The server needs to update the file catalog.
-Users can publish the files they have on the server.
-Users can report the cancellation of the publication of certain files.
